# AI Chat Companion v2.0 - Enhancements Plan

## 📅 Date: 2026-01-22
## Status: In Progress

## 1. Overview
Building upon the v1.0 foundation, v2.0 aims to bring "CozyPal" to life with rich animations, persistent memory, and proactive capabilities. The goal is to transform it from a passive chatbot into an active, empathetic study partner.

## 2. Key Features

### 2.1 Rich Avatar Animations (UI/UX)
*   **Goal**: Replace the static emoji with a lively SVG character.
*   **States**:
    *   **Idle**: Gentle breathing, occasional blinking.
    *   **Thinking**: Looking up/around when processing AI response.
    *   **Speaking**: Mouth movement or subtle bounce when streaming text.
    *   **Focus Mode**: Wearing headphones or reading a book (triggered by timer state).
*   **Tech**: React + Framer Motion (SVG path animation).

### 2.2 Chat History Persistence (Backend)
*   **Goal**: Remember context across sessions.
*   **Schema**:
    *   `ChatHistory` table: `id`, `user_id` (optional/future), `session_id` (linked to learning session), `role` (user/ai), `content`, `created_at`.
*   **Logic**:
    *   Save messages to DB upon sending/receiving.
    *   Load recent history (last N messages) when opening the chat window.
    *   Inject recent history into Gemini context window for continuity.

### 2.3 Proactive Engagement (Frontend + AI)
*   **Goal**: AI initiates interaction at key moments.
*   **Triggers**:
    *   **Timer Start**: "Ready to focus? Let's do this!"
    *   **Halfway Point**: "You're doing great, keep going!"
    *   **Break Time**: "Time to stretch! 🧘"
*   **UI**: Non-intrusive "bubble" notifications above the avatar head, auto-dismissing.

### 2.4 Actionable AI (Command Parsing)
*   **Goal**: Control the app via natural language.
*   **Commands**:
    *   "Start a 25m timer" -> Sets duration & Starts.
    *   "I need a break" -> Switches to Short Break mode.
    *   "Change theme to Math" -> Updates theme.
*   **Implementation**:
    *   Client-side intent matching (Regex/Keyword) OR
    *   LLM Function Calling (structured output). *Decision: Start with simple intent matching for speed/cost, upgrade to LLM function calling if needed.*

### 2.5 Persona Switching
*   **Goal**: Customize the companion's personality.
*   **Options**:
    *   `gentle_encourager` (Default): Warm, supportive.
    *   `strict_coach`: Direct, no-nonsense, pushes for results.
    *   `funny_friend`: Uses humor, memes, and casual language.
*   **Config**: Add dropdown in Settings -> AI Companion.

## 3. Implementation Plan

### Phase 1: Visual Life (Current Focus)
1.  Design SVG Avatar component (`CozyAvatar.tsx`).
2.  Implement Framer Motion states (Idle, Thinking, Happy).
3.  Integrate into `CozyPal.tsx`.

### Phase 2: Memory (Backend)
1.  Create `ChatHistory` model & migration.
2.  Update `chat_service.py` to save/load history.
3.  Update frontend to fetch history on mount.

### Phase 3: Intelligence (Frontend Logic)
1.  Implement Proactive Message system (event listeners on Timer).
2.  Implement Command Parser hook.
3.  Add Persona selector in Settings.

## 4. Technical Constraints
*   **Performance**: SVG animations must be lightweight (no heavy Lottie files if possible to keep bundle small).
*   **Cost**: History injection increases token usage. Limit to last 10 messages.
